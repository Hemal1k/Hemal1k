### Hi, I make small apps for Windows 👋

Tidy tools in the look of Windows 11 (and one browser extension) – free, open source (MIT), most with an installer and a portable version for x64 and ARM64.
The easiest way to get them all: **[HeMi Launcher](https://github.com/Hemal1k/HeMiLauncher)** – installs them with one click and keeps them up to date.
All of them on **[hemal1k.github.io](https://hemal1k.github.io)**.
