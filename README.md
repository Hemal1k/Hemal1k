### Hi, I make small apps for Windows 👋

Tidy tools in the look of Windows 11 – free, open source (MIT), with installers and portable versions.
All of them on **[hemal1k.github.io](https://hemal1k.github.io)**.

| | App | |
|---|---|---|
| <img src="https://hemal1k.github.io/assets/hemidock.png" width="40"> | **[HeMiDock](https://github.com/Hemal1k/HeMiDock)** | A taskbar replacement: dock, Start menu, control center, calendar and window manager |
| <img src="https://hemal1k.github.io/assets/hemipix.png" width="40"> | **[HeMiPix](https://github.com/Hemal1k/HeMiPix)** | Convert photos between HEIC, JPG, PNG, WebP and TIFF – whole folders at once, smaller and cropped |
| <img src="https://hemal1k.github.io/assets/hemiunlocker.png" width="40"> | **[HeMiUnlocker](https://github.com/Hemal1k/HeMiUnlocker)** | See which program holds a file or folder – and close it |
| <img src="https://hemal1k.github.io/assets/hemipad.png" width="40"> | **[HeMiPad](https://github.com/Hemal1k/HeMiPad)** | Notepad in the Windows 11 look: dark mode, JSON / YAML colours, spell check, no internet |
| <img src="https://hemal1k.github.io/assets/hemidark.png" width="40"> | **[HeMi Dark](https://github.com/Hemal1k/HeMiDark)** | A dark Windows 11 style skin for VLC – 9 colours, every screen scaling |
